# Find Who? 🕵️

A party game of fun "Find who..." posters. Open `index.html`, pick a poster, download/share it with friends, and let everyone point at the culprit.

- 30 predefined posters in 5 categories (Funny, Foodie, Chaos, Squad, Savage)
- Download as PNG or share via your phone's share sheet
- Add your own in the `P` array in `index.html`
