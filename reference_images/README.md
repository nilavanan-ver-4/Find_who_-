# Reference images (not bundled)

Put third-party reference images here **only for your own comparison** while you design or
commission original artwork. Everything in this folder except this README is git-ignored and is
never listed in `pubspec.yaml`, so it can't end up inside the app.

Do not move an image into `assets/memes/` or a template pack until you have verified that you have the
rights to distribute it (own work, a licence that allows it, or written permission).
